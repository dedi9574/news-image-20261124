  kills 24; about 30 workers still missing.

  Saryu-Kamala Express; the first train reaches Janakpur this morning.
- **COP31 in ruins:** climate talks in Antalya collapse with no deal after

- **153 drones overnight:** Russia fires 153 drones at Ukraine, 60 of them
  jet-powered; Kyiv region counts its dead after a block of flats collapses.
- **Court: Myanmar guilty:** the World Court finds Myanmar committed
  genocide against the Rohingya — the first state ever held responsible —
  and orders reparations.
- **Verstappen wins Vegas:** Max Verstappen takes a chaotic Las Vegas GP,
  beating Norris by 0.639 seconds.
- **Sport:** New Zealand bat out the final day to draw the Wellington Test;
  India declared on 720/9, Pant 128.

All headlines were verified against real news sources on 24 November 2026.

## How to run

```sh
python3 main.py
```

This renders the front page and saves it as `entry.png` next to `main.py`
(and also copies it to `$MAKEFUN_OUTPUT_DIR/entry.png` when that variable
is set). The program is deterministic: running it twice produces
identical output bytes.
